## 📋 Sobre o projeto

Sistema desenvolvido para **automatizar e organizar o controle de infiltrações** de uma empresa. As recepcionistas registram as ocorrências através de um formulário online simples e intuitivo. A partir desse registro, o sistema dispara automaticamente uma notificação por email e armazena os dados numa planilha para acompanhamento e histórico.

---

## ✨ Funcionalidades

- 📝 **Formulário de registro** — interface simples para as recepcionistas registrarem ocorrências
- 📧 **Notificação automática por email** — envio imediato ao registrar uma nova infiltração
- 📊 **Armazenamento em planilha** — dados salvos automaticamente no Google Sheets para acompanhamento
- 📱 **Responsivo** — funciona no celular e computador
- ⚡ **Registro rápido** — processo simples e rápido para não atrapalhar o fluxo de trabalho

---

## 🔄 Como funciona

```
Recepcionista preenche o formulário
        ↓
Sistema recebe os dados
        ↓
Email automático é enviado para a equipe
        ↓
Dados salvos na planilha de acompanhamento
```
